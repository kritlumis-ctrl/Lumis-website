01 Claude คืออะไร?

08 Project คืออะไร?
จากถามทีละครั้ง สู่ผู้ช่วยที่รู้งานคุณ
ได้กลับไป › เข้าใจโครงสร้าง Project 4 ชิ้น พร้อมออกแบบ Project ของตัวเอง
+

จะได้เรียนรู้อะไร

  • ทำไมการถาม AI ทีละครั้งถึงไม่พอ — ต้องเล่าบริบทใหม่ ก็อปวางเอง และผลลัพธ์ไม่นิ่ง
  • 4 ส่วนประกอบของ Project: Instructions (วิธีทำงาน) · ไฟล์อ้างอิง (ข้อมูลและ template) · Skills (ขั้นตอนมาตรฐาน) · Connectors (เครื่องมือที่ใช้อยู่)
  • Project ทำงานกับไฟล์และโฟลเดอร์ของคุณได้ตรง ๆ และรับเป้าหมายแล้วทำหลายขั้นต่อจนจบ

✍️ เปิดดู Project ตัวอย่างที่ใช้ทำงานจริง แล้วแยกส่วนประกอบทีละชิ้น
