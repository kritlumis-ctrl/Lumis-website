สมัคร Claude แผน Pro

⏱ 5 นาที · จำเป็น

ทำไม: ฟีเจอร์ Project ที่ใช้ในคลาส ใช้ได้เฉพาะแผนที่เสียเงิน (แผน Free ใช้ไม่ได้)

1
เข้า claude.ai สมัครด้วย Google หรืออีเมล
2
เปิด claude.com/pricing เลือก Pro แล้วกด Try Claude
3
เลือกจ่าย รายเดือน USD 20 หรือ รายปี (เฉลี่ย USD 17/เดือน) ด้วยบัตรของตัวเอง
✅ ผ่านแล้ว: ใน Settings ขึ้นว่าเป็นแผน Pro
💡 หน้า pricing โชว์ $17 ตัวใหญ่ คือราคาเฉลี่ยต่อเดือนเมื่อจ่ายรายปี ถ้าจ่ายรายเดือนคือ $20 (เขียนตัวเล็กไว้ใต้ราคา)
💡 ใช้บัญชีบริษัท (Team / Enterprise) ก็ได้ แต่บางองค์กรต้องให้ Admin เปิดสิทธิ์ Cowork ก่อน · ราคา ณ พ.ย. 2569

ติดตั้งโปรแกรม Claude Desktop

⏱ 5 นาที · จำเป็น

ทำไม: ให้ Claude ทำงานกับไฟล์ในเครื่องได้ ต้องใช้โปรแกรม ไม่ใช่หน้าเว็บ

1
เปิด claude.com/download · Mac กด Download for macOS · Windows เลื่อนลงไปที่แถว Windows
2
เปิดไฟล์ที่โหลดมา · Mac ลากไอคอน Claude ไปที่ Applications · Windows ดับเบิลคลิกไฟล์ .exe
3
เปิดแอป กด Log in ด้วยบัญชีเดียวกับขั้นที่ 1 แล้วพิมพ์ "สวัสดีครับ"
✅ ผ่านแล้ว: Claude ตอบกลับข้อความทักทาย
💡 เครื่องบริษัทถามรหัส Admin = ติดตั้งเองไม่ได้ ให้ติดต่อ IT หรือใช้โน้ตบุ๊กส่วนตัว · ต้องเป็น macOS 11 หรือ Windows 10 ขึ้นไป

ตั้ง Instructions for Claude

⏱ 10 นาที · จำเป็น · ทำครั้งเดียว ใช้ได้ทุกแชท

ทำไม: แนะนำตัวกับ Claude ครั้งเดียว แล้วไม่ต้องบอกซ้ำทุกแชท (ในคลาสเรียกส่วนนี้ว่า Global Instructions)

เตรียม 2 ไฟล์
📄 Instructions for Claude - Setup Kit.docx (ดาวน์โหลดจากลิงก์ที่ผู้สอนแชร์ใน LINE)
📄 CV ของตัวเอง ลบเบอร์โทร ที่อยู่ เลขบัตร และเงินเดือนออกก่อน (ไม่มี CV ใช้ JD แทนได้)
1
กด New chat → กด + แนบ 2 ไฟล์ → วางข้อความด้านล่าง แล้วกด Enter
อ่านไฟล์ "Instructions for Claude – Setup Kit" และ CV ที่แนบมา แล้วเขียน Instructions for Claude ให้ฉัน โดยทำตามขั้นตอนในไฟล์ Setup Kit
2
Claude จะ ถามคำถามสั้นๆ ก่อนเขียน ตอบสั้นๆ ได้ ข้อไหนไม่แน่ใจพิมพ์ว่า "เลือกให้"
3
Claude ส่งชุดคำสั่งมาในกล่องเดียว อ่านทวน ไม่ตรงตรงไหนบอกให้แก้ แล้วกด Copy
4
กดชื่อ/รูปโปรไฟล์ (ซ้ายล่าง) → Settings → Your Claude → ช่อง Instructions → วางทับข้อความเดิม (ถ้ามีปุ่ม Save ให้กด)
✅ ผ่านแล้ว: เปิดแชทใหม่ แล้วลองทดสอบ 3 ข้อตามส่วน C ใน Setup Kit · Claude เรียกชื่อและใช้น้ำเสียงถูก และแก้ข้อมูลผิดให้ ไม่คล้อยตาม
💡 หาช่องไม่เจอ พิมพ์ Instructions ในช่อง Search ของหน้า Settings · ชื่อเดิมของช่องนี้คือ "Instructions for Claude" หรือ "What personal preferences should Claude consider in responses?"

ติดตั้ง Skill

⏱ 10 นาที · จำเป็น

ทำไม: Skill คือ "คู่มือสำเร็จรูป" ที่ทำให้ Claude ทำงานบางอย่างได้เป็นขั้นตอนและได้ผลสม่ำเสมอ

Skill ที่แจก 7 ตัว
⭐ Project Builder — พาสร้าง Project จากงานของคุณทีละขั้น ได้ Project Instructions พร้อมใช้
⭐ CTFC Prompt Coach — ตรวจและปรับ prompt ให้ครบ Context · Task · Format · Constraint
⭐ Output Checker — ตรวจงานที่ Claude ทำมาก่อนส่ง เช็กตัวเลขและข้อมูลที่ไม่มีที่มา
📦 Workflow Transformer — แปลงงานที่ทำซ้ำเป็น Workflow พร้อมชุด Prompt
📦 Prompt Optimizer — ปรับ prompt ขั้นสูง รวมถึง System Prompt และ Instructions
📦 World-Class Slide Design — ออกแบบสไลด์มาตรฐานบริษัทที่ปรึกษา พร้อม Speaker Notes
📦 McKinsey SCR Framework — วางเรื่องนำเสนอผู้บริหารแบบ SCR (สถานการณ์ → ปัญหา → ทางออก)
⭐ = แนะนำให้ติดตั้งก่อน · ไฟล์ทั้งหมดอยู่ในโฟลเดอร์ Skills บน Google Drive
1
เปิดลิงก์ Google Drive ใน LINE แล้วดาวน์โหลดไฟล์ .skill (ไม่ต้องแตกไฟล์)
2
ใน Claude กดเมนู Plugins ที่แถบซ้าย (ไม่เห็น ให้ไปที่ Settings → Plugins) · เช็กใน Settings → Capabilities ว่าสวิตช์ Create and edit files เปิดอยู่
3
กด Add → Upload plugin แล้วลากไฟล์ .skill ที่โหลดมาใส่ (ใส่หลายไฟล์พร้อมกันได้) → กด Upload
✅ ผ่านแล้ว: หน้า Plugins กดตัวกรอง Skills แล้วเห็นชื่อ Skill ในรายการ (อย่างน้อย 1 ตัว แนะนำ 3 ตัวที่มี ⭐ ครบ 7 ตัวยิ่งดี)

ต่อ Connector 1 ตัว

⏱ 5 นาที · จำเป็น

ทำไม: ให้ Claude อ่านอีเมลและไฟล์ในไดรฟ์ได้เอง ไม่ต้อง copy-paste · เลือกตัวที่ไฟล์งานคุณอยู่จริง: Gmail / Outlook / Google Drive / OneDrive

1
กดเมนู Plugins → Connectors พิมพ์ชื่อบริการในช่องค้นหา แล้วกด Connect
2
ล็อกอินด้วย บัญชีบริษัท แล้วกด Allow
3
กลับมาที่ Claude ปุ่ม Connect ข้างชื่อบริการจะหายไป
✅ ผ่านแล้ว: พิมพ์ "สรุปอีเมล 3 ฉบับล่าสุดของฉัน" แล้ว Claude ตอบได้
⚠️ ให้สิทธิ์เท่าที่จำเป็น · ข้อมูลที่มีตัวเลขลูกค้า เช็ก policy กับ IT ก่อน

ตั้ง Model เริ่มต้น

⏱ 2 นาที · จำเป็น

ทำไม: เลือกรุ่นให้เหมาะกับงาน ช่วยประหยัดโควตาการใช้งาน

1
คลิก ชื่อ Model ข้างช่องพิมพ์ แล้วเลือก Sonnet (รุ่นล่าสุดในเมนู)
จำง่ายๆ Haiku = งานง่าย เร็ว · Sonnet = งานประจำวัน (ตั้งเป็นค่าเริ่มต้น) · Opus = งานยาก วิเคราะห์ลึก
✅ ผ่านแล้ว: ช่องพิมพ์แชทขึ้นชื่อ Sonnet
7

ติดตั้ง Claude ใน Excel / PowerPoint

⏱ 5 นาที · จำเป็น

ทำไม: เรียกใช้ Claude ในหน้าต่าง Excel, PowerPoint และ Word ได้เลย · ต้องเป็น Microsoft 365 (Excel 2016 / 2019 แบบซื้อขาดใช้ไม่ได้)

1
ค้นหา "Claude for Microsoft 365" ใน Microsoft Marketplace แล้วกด Get it now
2
เปิด Excel → Add-ins (Windows: แท็บ Home · Mac: เมนู Tools) → เลือก Claude
3
ล็อกอินบัญชี Claude ใน panel ด้านขวา (ใช้ได้ทั้ง Excel, PowerPoint และ Word)
✅ ผ่านแล้ว: เห็น panel ของ Claude ด้านขวาใน Excel และพิมพ์คุยได้
💡 บริษัทปิดการติดตั้ง Add-in ไว้ ข้ามขั้นนี้ได้ ดู demo ในคลาสแทน
8

ลองให้ Claude เปิดโฟลเดอร์ในเครื่อง

⏱ 5 นาที · จำเป็น

ทำไม: นี่คือหัวใจของ Project ในคลาส Claude จะอ่านและสร้างไฟล์ในโฟลเดอร์ที่คุณอนุญาตได้เอง (ในแอปปุ่มนี้อาจชื่อ Cowork)

1
หน้าแรกของแอป กดปุ่ม Project or folder ใต้กล่องพิมพ์
2
เลือกโฟลเดอร์ที่ ไม่มีข้อมูลสำคัญ ถ้ามีหน้าต่างถามสิทธิ์ กด Allow
3
พิมพ์ "ในโฟลเดอร์นี้มีไฟล์อะไรบ้าง" แล้วกด Enter
✅ ผ่านแล้ว: Claude บอกชื่อไฟล์ในโฟลเดอร์ของคุณได้ถูกต้อง
💡 ต้องใช้โปรแกรม Desktop · โฟลเดอร์นี้ใช้ทดลองเท่านั้น วันเรียนจะลบการเชื่อมต่อออกในห้อง
9

เตรียมไฟล์งานของตัวเอง

⏱ 10 นาที · จำเป็น

ทำไม: ฝึกกับงานของตัวเอง จะเห็นประโยชน์ชัดกว่าไฟล์ตัวอย่างมาก

1
สร้างโฟลเดอร์ชื่อ Claude Class
2
ดาวน์โหลด ไฟล์ประกอบการเรียน จากลิงก์ที่ทีมงานส่งให้ใน LINE แตกไฟล์ไว้ในโฟลเดอร์นี้
3
คัดลอก ไฟล์งานจริง 1–2 ไฟล์ มาไว้ด้วย เช่น Excel สรุปตัวเลข บันทึกประชุม หรือเอกสารที่อยากให้ช่วยย่อ
⛔ ห้ามใช้ข้อมูลลับ ข้อมูลลูกค้า หรือข้อมูลส่วนบุคคล
มีชื่อ เบอร์โทร เลขบัตร ให้ลบหรือเปลี่ยนเป็นข้อมูลสมมติก่อน · ไม่สะดวกใช้ไฟล์จริง ใช้ไฟล์ตัวอย่างในคลาสได้
✅ ผ่านแล้ว: ในโฟลเดอร์ Claude Class มีไฟล์ประกอบการเรียน และไฟล์งานที่ปลอดภัยอย่างน้อย 1 ไฟล์
10

จดโจทย์สำหรับ Project

⏱ 5 นาที · แนะนำ

ทำไม: ในคลาสจะสร้าง Project จากงานของคุณเอง จดไว้ก่อนจะเริ่มได้เร็ว

1
เลือก งาน 1 งาน จากไฟล์ในขั้นที่ 9 แล้วจดคำตอบ 3 ข้อ
ใช้ไฟล์อะไร — เช่น ยอดขาย.xlsx + เป้าหมาย.xlsx
อยากได้ผลลัพธ์แบบไหน — เช่น สรุป 1 หน้า + กราฟ
มี KPI อะไรที่ต้องรายงาน — เช่น ยอดขายเทียบเป้า, 3 สินค้าขายดี
✅ ผ่านแล้ว: มีโน้ต 3 ข้อ พร้อมใช้ตอนสร้าง Project ในคลาส
